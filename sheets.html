📊 Method 1: Google Sheets → Download → Import Easiest

1️⃣

Open Your Google Sheet

Go to sheets.google.com and open the sheet with your leads/data

2️⃣

Format Your Columns

Make sure your sheet has these column headers in Row 1:

Name   Phone   Email   Company   Project Type   Location   Budget   Status   Source   Notes

3️⃣

Download as CSV

Click File → Download → Comma Separated Values (.csv)

4️⃣

Import to CRM

Go to Import tab above → Upload the CSV file → Map columns → Click Import!

🔄 Method 2: Google Forms → Sheets → CRM Auto Capture

1️⃣

Create Google Form

Go to forms.google.com → Create a lead capture form with fields: Name, Phone, Email, Project Type, Location, Budget, Message

2️⃣

Link Form to Sheets

In Google Form → Click Responses tab → Click Google Sheets icon → Create new spreadsheet

3️⃣

Embed Form on Website

In Google Form → Click Send → Embed → Copy the HTML code → Paste on your website contact page

4️⃣

Export & Import Periodically

Every few days → Download CSV from Sheets → Import here to keep CRM updated!

⚡ Method 3: Zapier Auto Sync (Advanced) Auto Sync

Zapier connects Google Sheets to your CRM automatically!

When a new row is added to Google Sheets, Zapier automatically sends the data to your CRM via webhook — no manual export needed! Free plan available at zapier.com

1️⃣

Create Zapier Account

Go to zapier.com → Sign up free → Create new Zap

2️⃣

Set Trigger: Google Sheets

Choose Google Sheets as trigger → Select event: New Spreadsheet Row → Connect your Google account → Select your sheet

3️⃣

Set Action: Webhook

Choose Webhooks by Zapier as action → Select: POST → Enter your CRM URL → Map the fields

4️⃣

Test & Activate

Test the Zap → Turn it ON → Now every new Sheet row auto-syncs to your CRM! 🎉
