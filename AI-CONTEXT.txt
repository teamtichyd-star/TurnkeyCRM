NOTIFICATION SYSTEM (FULLY DOCUMENTED)
=======================================================

✅ HOW IT WORKS:
- Call TIC_NOTIF.send(db, userName, message, type, link)
- Auto-resolves userName → email via users collection
- Writes to 'notifications' collection
- Bell badge updates real-time (onSnapshot listener)
- OS notification fires if Notification.permission granted

📍 WHERE TIC_NOTIF.send IS CALLED:
- projects.html (4 places): new project, update, manager assign, snag
- tasks.html (2 places): new + update
- leads.html (2 places): new + update
- followups.html (2 places): new + update
- client-view.html (1 place): client adds snag → notify project manager

🔔 BELL HTML LOCATION:
- File: index.html (parent shell, NOT in iframes)
- Element IDs: notifBell, bellIcon, notifCount
- Click handler: showNotifications()
- Real-time listener: listenNotifications(userEmail) using onSnapshot
- Variable: window._notifUnsub (unsubscribe handle)

🎯 WEB PUSH (OS NOTIFICATIONS):
- Permission button: enablePushNotifications() in index.html
- Uses service worker: navigator.serviceWorker.ready.showNotification()
- Service worker file: sw.js (handles notification clicks)
- Icon URL: https://teamtichyd-star.github.io/TurnkeyCRM/icon-192.png
- Sound + vibration: vibrate: [300, 100, 300, 100, 300]

DEBUGGING TIPS:
=======================================================
- Bell not updating? → Check listenNotifications() called on login
- Notification not sending? → Check Firestore 'notifications' collection
- Web push not firing? → Check Notification.permission === 'granted'
- Service worker cached? → Chrome → site settings → clear & reset
- Check console for: "✅ Notification sent to..." (confirms TIC_NOTIF works)
